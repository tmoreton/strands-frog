The Wi-Fi setup page uses the official Strands Agents [frog-hop.svg](https://github.com/strands-agents/harness-sdk/blob/0b68b8aa5113709f3bf3aaab72a434752ce2330c/site/src/assets/nav/frog-hop.svg). See the accompanying Apache 2.0 license and copyright notice.

The Waveshare display uses the smooth illustration in `charm-frog.svg` and the costume overlays in `wizard-hat.svg` and `garden-crown.svg`. After editing the artwork or poses, run `uv run assets/render_frog.py` from the firmware directory to regenerate the bundled image data. The firmware build needs no SVG renderer.
